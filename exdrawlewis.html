Anleitung

1 · Element wählen

Tippe im Periodensystem auf ein Element. Es bleibt gewählt, bis du ein anderes antippst. Mit Tastatur: Elementsymbol tippen, z.B. O oder C L für Cl.

2 · Zeichnen (Werkzeug «Zeichnen»)

  • Leere Fläche antippen: neues einzelnes Atom.
  • Atom antippen: ein neues Atom des gewählten Elements wird mit einer Einfachbindung angebunden.
  • Bindung antippen: Einfach- → Doppel- → Dreifachbindung → Einfachbindung.
  • Von einem Atom zu einem anderen ziehen: Bindung zwischen diesen beiden Atomen, z.B. für Ringe. Ziehst du ins Leere, entsteht dort ein neues Atom.

3 · Freie Elektronenpaare und Ladungen (Werkzeug «Auswählen»)

  1. Wechsle zum Werkzeug «Auswählen».
  2. Tippe ein oder mehrere Atome an. Oder ziehe auf der leeren Fläche einen Rahmen um die Atome.
  3. Unten stehen die Knöpfe + und − für «Elektronenpaar», «Einzelelektron» und «Ladung». Jeder Tipp wirkt auf alle ausgewählten Atome.

Freie Elektronenpaare und Einzelelektronen (Radikale) ordnen sich automatisch um das Atom an.

4 · Verschieben, ersetzen, löschen (Werkzeug «Auswählen»)

  • Atom ziehen: verschiebt es. Sind mehrere Atome ausgewählt, bewegen sie sich gemeinsam. «Alle» wählt die ganze Zeichnung aus.
  • «Element → …» ersetzt die ausgewählten Atome durch das Element, das im Periodensystem gewählt ist.
  • «Löschen» entfernt ausgewählte Atome und Bindungen. Taste: Entf oder ⌫.
  • Rückgängig und Wiederholen mit den Pfeilen oben. Tasten: Ctrl/⌘+Z und Ctrl+Y bzw. ⌘+⇧+Z.

5 · Ansicht

  • Zwei Finger auf der Fläche: zoomen und verschieben. Im Werkzeug «Zeichnen» verschiebt auch das Ziehen auf der leeren Fläche die Ansicht.
  • Lupen rechts oben auf der Fläche: vergrössern und verkleinern. Der Knopf dazwischen zeigt die ganze Zeichnung.
  • PSE blendet das Periodensystem aus, damit du mehr Platz hast. Häufige Elemente bleiben dann als Kurzwahl sichtbar.
  • Tasten 1 und 2 wechseln zwischen «Zeichnen» und «Auswählen».

6 · Abgeben

Bist du fertig, tippe auf «Antwortcode». Trage den 8-stelligen Code in isTest ins Antwortfeld ein, mit «Kopieren» und Einfügen oder durch Abtippen. Jede Änderung an der Zeichnung ergibt einen neuen Code. Erstelle den Code deshalb erst ganz am Schluss.

Deine Zeichnung bleibt auf diesem Gerät gespeichert, auch wenn die Seite neu lädt. Die App sendet keine Daten.

Für Lehrpersonen

Lösungscode erstellen

Zeichne die richtige Lewis-Formel und öffne «Antwortcode». Hinterlege diesen Code in isTest als richtige Antwort, z.B. im Fragetyp «Einfacher Text». Sind mehrere Formeln richtig (z.B. Grenzformeln), trägst du jeden Code als Alternative ein.

Der Code hängt nur von den Atomen, Bindungen, freien Elektronenpaaren, Einzelelektronen und Ladungen ab. Wo die Atome liegen und auf welcher Seite die Elektronenpaare sitzen, spielt keine Rolle. Erstelle Lösungscodes mit derselben Version der App, die auch in der Prüfung läuft (Code-Version ).

Mit der Einstellung abgabe=zeichnung oder abgabe=beide erhalten die Lernenden einen langen Zeichnungscode (für eine «Offene Frage»). Füge ihn hier ein, um die Zeichnung zu sehen:

Einstellungen über die Adresse

Beispiel: …/lewis-editor/?id=a1&pruefung=nov26. Die gleichen Werte lassen sich oben im Quelltext im Block «EINSTELLUNGEN» festlegen (nötig beim Einbetten als Code, z.B. in Google Sites).

ParameterWirkung
idEindeutiger Name der Aufgabe. Nötig, wenn eine Prüfung mehrere Lewis-Aufgaben enthält, sonst teilen sie sich den Speicher.
paarestrich (Standard) oder punkte.
abgabecode (Standard), zeichnung oder beide.

elementeNur diese Elemente anbieten, z.B. H,C,N,O.

startAnfangs gewähltes Element, z.B. H.
